# 数字图像处理课程大作业：低光照彩色图像增强算法的改进与对比

## 一、项目简介
针对夜间、室内背光、阴天等**光照不足**场景下采集到的图像整体偏暗、对比度低、细节难以辨认的问题，
本项目实现并对比了两种彩色图像增强方法：

- **基础版（Baseline）**：直接对 BGR 三个通道分别做全局直方图均衡化（HE）；
- **改进版（Improved）**：在 HSV 空间只对亮度通道 V 做 CLAHE（限制对比度自适应直方图均衡化），
  再做伽马提亮，色调 H、饱和度 S 保持不变。

实验结果表明：基础版虽然提亮了图像，但会出现明显的**颜色失真**；改进版在显著提亮的同时
颜色自然、细节清晰，整体效果更优。

## 二、项目结构
```
.
├── enhance_baseline.py   # 基础版：BGR三通道全局直方图均衡化
├── enhance_improved.py   # 改进版：HSV空间 V通道 CLAHE + 伽马提亮
├── run_comparison.py     # 结果对比与评估脚本（生成对比图、直方图、定量指标）
├── data/                 # 标准测试图像（lena、baboon、fruits）
├── results/              # 增强结果、对比图、直方图、指标

```

## 三、运行方法
环境依赖：Python 3、`opencv-python`、`numpy`、`matplotlib`
```bash
# 安装依赖
pip install opencv-python numpy matplotlib

# 运行对比脚本（自动生成全部结果到 results/ 目录）
python run_comparison.py

# 也可单独运行基础版 / 改进版
python enhance_baseline.py
python enhance_improved.py
```

## 四、方法说明
| 对比项 | 基础版 | 改进版 |
|---|---|---|
| 颜色空间 | BGR，三通道分别处理 | HSV，只处理亮度通道 V |
| 增强算法 | 全局直方图均衡化（HE） | CLAHE + 伽马提亮（γ=0.45） |
| 颜色 | 容易失真、偏色 | 色调饱和度保持、颜色自然 |
| 局部对比度 | 全局映射，易过度增强 | 分块自适应，限制对比度、抑制噪声 |

## 五、定量指标（以 Lena 为例）
| 版本 | 平均亮度 | 标准差 | 信息熵 | 平均梯度 |
|---|---|---|---|---|
| 低光照 | 85.59 | 53.70 | 7.484 | 8.43 |
| 基础版 | 128.40 | 72.55 | 7.977 | 12.30 |
| 改进版 | 123.87 | 49.47 | 7.557 | 10.97 |

## 六、结论
改进版通过“HSV 空间只增强亮度通道”和“CLAHE 结合伽马提亮”两处修改，
在有效提升低光照图像亮度和清晰度的同时，克服了基础版颜色失真、过度增强和噪声放大的问题，
增强结果颜色自然、细节清晰，整体效果明显优于基础版。
